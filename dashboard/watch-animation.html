Concept watch

Your heart, one glance away.

A watch face for Moni-Buddy. It shows the numbers the SK-AM62B board finishes processing, so you see the result without opening the dashboard.

Scroll to wake it

1 · Signal

The rhythm draws itself.

The AFE4950 records ECG at 500 samples per second. The board filters it and marks every R-peak. The watch draws the trace.

2 · Baseline

It learns your normal.

The ring fills as heart rate locks on. At 93 BPM with signal quality 97, the state reads normal. The twin keeps this as your baseline.

3 · Alert

A change gets noticed.

When heart rate climbs well above baseline, the ring turns blush pink and the watch buzzes. This is a simulated 128 BPM event for the demo.

4 · System

From board to wrist.

Three steps carry one result from the sensor to the watch.

SK-AM62B board FILTER + R-PEAKS

Cleans the recording, drops bad beats, scores signal quality once per second.

CardioTwin dashboard TWIN

Draws the waveform, keeps the baseline, flags a state and a risk number.

Moni-Buddy backend EVENT

Stores each event so the care dashboard and the watch show the same result.
